Как получить GitHub Token

1. Откройте github.com/settings/tokens/new
2. Дайте токену имя, например Tempus Admin
3. В разделе Select scopes поставьте галочку repo
4. Нажмите «Generate token» и скопируйте — он показывается только один раз
5. Вставьте токен при следующем входе в эту панель

Структура файлов

Все данные сайта хранятся в файле data.json в вашем репозитории.
Фотографии загружаются как base64 прямо в этот файл — дополнительных папок не нужно.
Максимальный размер одного фото: ~2 МБ (браузер сжимает автоматически).
